# Modalità ospite — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** chi apre il sito senza account può guardare l'app (dati d'esempio, sola lettura) e il feed vero dei post pubblici, e ogni azione porta a "Crea un account".

**Architecture:** un flag in `sessionStorage` fa disegnare a `Root` (App.jsx) un `AppOspite` al posto di `UserGate`. `AppOspite` mette sopra le pagine vere un `AccountContext` e uno `StoreContext` finti (`components/Ospite.jsx`), costruiti da un esempio generato con le funzioni dell'app (`data/ospite.js`); le funzioni che scrivono aprono un foglio "Crea un account". Le rotte non in elenco mostrano una pagina chiusa. Il feed usa una funzione SQL nuova, leggibile da `anon`.

**Tech Stack:** React 19 + Vite, Supabase (Postgres, RPC), test con `node --test` (loader inline per gli import senza estensione).

**Spec:** `docs/superpowers/specs/2026-11-25-ospite-design.md`

## Global Constraints

- Branch `ospite`. Mai push (lo fa l'utente). Mai `context.md` né `docs/*.md` (CLAUDE.md).
- Database: solo additivo. La migrazione NON si applica senza l'OK esplicito dell'utente; `.env` oggi punta a **produzione**.
- Testi dell'interfaccia in italiano, col tono dell'app.
- Nessuna dipendenza nuova.
- Verifica finale: `npm run lint` e `npm run test` puliti.

import { useSyncExternalStore } from 'react'

// ---------------------------------------------------------------------------
// La modalità ospite: chi non ha un account guarda l'app senza entrare.
// Il flag sta in sessionStorage: resta col ricaricare, finisce chiudendo la
// scheda del browser. I dati sono un esempio (data/ospite), il feed è vero
// (pages/FeedOspite). Niente si scrive: ogni azione chiede l'account.
// ---------------------------------------------------------------------------

const CHIAVE = 'palestra:ospite'
const CHIAVE_POI = 'palestra:ospite-poi'
const CAMBIO_OSPITE = 'palestra:ospite-cambio'
export const EVENTO_ACCOUNT = 'palestra:chiedi-account'

export function inOspite() {
  try {
    return sessionStorage.getItem(CHIAVE) === '1'
  } catch {
    return false
  }
}

function avvisa() {
  globalThis.dispatchEvent?.(new Event(CAMBIO_OSPITE))
}

export function entraOspite() {
  try {
    sessionStorage.setItem(CHIAVE, '1')
  } catch {
    /* niente storage: l'ospite dura finché non si ricarica */
  }
  avvisa()
}

/** `poi`: la schermata di UserGate da cui ripartire ('crea'), o null. */
export function esciOspite(poi = null) {
  try {
    sessionStorage.removeItem(CHIAVE)
    if (poi) sessionStorage.setItem(CHIAVE_POI, poi)
  } catch {
    /* come sopra */
  }
  avvisa()
}

/** La schermata chiesta uscendo dall'ospite, una volta sola. */
export function prendiSchermataDopoOspite() {
  try {
    const poi = sessionStorage.getItem(CHIAVE_POI)
    sessionStorage.removeItem(CHIAVE_POI)
    return poi
  } catch {
    return null
  }
}

function iscriviti(avvisami) {
  globalThis.addEventListener?.(CAMBIO_OSPITE, avvisami)
  return () => globalThis.removeEventListener?.(CAMBIO_OSPITE, avvisami)
}

export function useOspite() {
  return useSyncExternalStore(iscriviti, inOspite, () => false)
}

// Le pagine che un ospite vede. Le altre (modificare, importare, allenarsi,
// tutto il sociale tranne il feed, il lavoro da PT) → components/Ospite,
// PaginaChiusa. ⚠️ Una pagina nuova si aggiunge qui solo se regge senza
// account: legge da useStore/useAccount, non da Supabase.
export const ROTTE_OSPITE = [
  'inizio',
  'home',
  'scheda',
  'calendario',
  'recap-mese',
  'svolto',
  'dieta',
  'dieta-oggi',
  'dieta-vista',
  'dieta-storico',
  'dieta-schema',
  'dieta-peso',
  'esercizi',
  'esercizi-gruppo',
  'feed',
]

export const rottaPerOspite = (nome) => ROTTE_OSPITE.includes(nome)

/**
 * Apre il foglio "Crea un account" (components/Ospite, FoglioAccount). Solo
 * da un gesto: una funzione chiamata da un effetto, all'apertura di una
 * pagina, non deve far saltare fuori il foglio. `userActivation` è del
 * browser; dove non c'è si apre sempre.
 */
export function chiediAccount(cosa) {
  const gesto = globalThis.navigator?.userActivation
  if (gesto && !gesto.isActive) return undefined
  globalThis.dispatchEvent?.(new CustomEvent(EVENTO_ACCOUNT, { detail: cosa }))
  return undefined
}

/** Lo stesso oggetto, ma ogni funzione (tranne `letture`) chiede l'account e non fa niente. */
export function soloLettura(valore, chiedi = chiediAccount, letture = []) {
  const out = {}
  for (const [k, v] of Object.entries(valore)) {
    out[k] = typeof v === 'function' && !letture.includes(k) ? () => chiedi(k) : v
  }
  return out
}
```

// L'atleta d'esempio della modalità ospite (lib/ospite). Fatto con le stesse

const SCHEDA_ATTIVA = `Giorno A - Petto e tricipiti
Panca piana 4x8 70kg rec 2min
Spinte manubri inclinata 3x10 26kg rec 90s
Croci ai cavi 3x12 15kg rec 60s
Push down 3x12 25kg rec 60s

Giorno B - Schiena e bicipiti
Trazioni 4x6 rec 2min
Rematore bilanciere 4x8 60kg rec 2min
Lat machine 3x10 55kg rec 90s
Curl manubri 3x12 14kg rec 60s

Giorno C - Gambe e spalle
Squat 4x6 90kg rec 3min
Stacco rumeno 3x8 80kg rec 2min
Leg press 3x12 160kg rec 90s
Military press 4x8 40kg rec 2min
Alzate laterali 3x15 8kg rec 60s`

const SCHEDA_VECCHIA = `Full body
Squat 3x10 70kg rec 2min
Panca piana 3x10 60kg rec 2min
Rematore manubrio 3x10 24kg rec 90s
Plank 3x45s rec 60s`

const COLORI = ['verde', 'verde', 'giallo', 'verde', 'rosso']

// Un allenamento fatto: tutte le serie chiuse, un'ora e dieci.
function fatto(scheda, giorno, settimana, data) {
  const s = creaSessione(scheda, giorno, settimana)
  s.inizio = new Date(data.getTime() - 70 * 60000).toISOString()
  s.esercizi = s.esercizi.map((e, i) => ({
    ...e,
    sets: e.sets.map((_, j) => serieChiusa(e.schema, j, COLORI[(i + j) % COLORI.length])),
  }))
  const { daSalvare: _, ...c } = riepilogoSessione(s, data.toISOString())
  return { ...c, visibilita: 'privata' }
}

function giorniFa(oggi, n, ora = 18) {
  const d = new Date(oggi)
  d.setDate(d.getDate() - n)
  d.setHours(ora, 30, 0, 0)
  return d
}

export function costruisciEsempio(oggi = new Date()) {
  const attiva = { ...parseSchedaTesto(SCHEDA_ATTIVA, 'Push Pull Legs'), attiva: true, giorniSettimana: [0, 2, 4] }
  const vecchia = { ...parseSchedaTesto(SCHEDA_VECCHIA, 'Full body inverno'), archiviata: true }

  // Tre allenamenti a settimana nelle ultime 4 settimane (lun, mer, ven circa).
  const giorni = attiva.giorni.filter((g) => g.tipo === 'workout')
  attiva.completamenti = [33, 31, 29, 26, 24, 22, 19, 17, 15, 12, 10, 8, 5, 3, 1].map((n, i) =>
    fatto(attiva, giorni[i % giorni.length], 1 + Math.floor(i / 3), giorniFa(oggi, n)),
  )
  attiva.settimanaCorrente = 5
  vecchia.completamenti = []

  const utente = {
    ...normalizzaUtente({
      id: null,
      nome: 'Marco',
      cognome: 'Esempio',
      username: 'marco.esempio',
      dati: { sesso: 'm', eta: 28, peso: 78, altezza: 180, movimento: 'leggero', obiettivo: 'ricomposizione' },
    }),
    ospite: true,
  }
  const preferenze = preferenzeVuote()
  const dieta = dietaDaDatiFisici(utente.dati, preferenze, { nome: 'Ricomposizione', attiva: true })

  return { utente, schede: [attiva, vecchia], diete: dieta ? [dieta] : [], preferenze, diario: [] }
}
```

```sql
-- ---------------------------------------------------------------------------
-- 2026-11-25 · Il feed per chi NON ha un account (modalità ospite, pages/FeedOspite).
--
-- Gli allenamenti pubblici degli account pubblici, gli ultimi prima, 20 alla
-- volta: la stessa regola del link a un post (`post_pubblico`), su un elenco.
-- In più, `pubblico` chiesto esplicitamente: a chi non ha un account
-- `vedo_contenuti_di` farebbe vedere anche i PT che non si allenano.
-- Le foto: solo le pubbliche e non in attesa della moderazione, il percorso
-- della copia nel bucket `feed` (pubblico già da prima, lib/fotoAllenamento).
-- Solo il nome, niente username: chi non ha un account non cerca persone.
-- Rilanciabile. Solo additiva.
-- ---------------------------------------------------------------------------

create or replace function public.feed_ospite(
  p_prima_di    timestamptz default null,
  p_prima_di_id text default null,
  p_quanti      int default 20
)
returns table (
  id        text,
  user_id   uuid,
  nome      text,
  scheda_id text,
  data      timestamptz,
  dati      jsonb,
  mi_piace  bigint,
  commenti  bigint,
  foto      jsonb
)
language sql stable security definer set search_path = public as $$
  select a.id,
         a.user_id,
         p.nome,
         a.scheda_id,
         a.data,
         public.dati_allenamento_per_me(a.user_id, a.dati),
         (select count(*) from public.allenamento_mi_piace m where m.allenamento_key = a.id),
         (select count(*) from public.allenamento_commenti c
           where c.allenamento_key = a.id and not public.in_attesa('commento', c.id)),
         coalesce((
           select jsonb_agg(jsonb_build_object(
                    'id', f.id, 'percorso', f.percorso, 'tipo', f.tipo, 'nome', f.nome,
                    'posizione', f.posizione, 'visibilita', f.visibilita, 'allenamento_key', f.allenamento_key)
                  order by f.posizione)
             from public.allenamento_foto f
            where f.user_id = a.user_id
              and (f.allenamento_key = a.id or f.allenamento_key = a.chiave_vecchia)
              and f.visibilita = 'pubblica'
              and not public.in_attesa('foto', f.id)
         ), '[]'::jsonb)
    from public.allenamenti a
    join public.profili p on p.id = a.user_id
   where a.visibilita = 'pubblica'
     and not a.da_salvare
     and p.pubblico
     and not public.pubblicazione_bloccata(a.user_id)
     and (p_prima_di is null or (a.data, a.id) < (p_prima_di, p_prima_di_id))
   order by a.data desc, a.id desc
   limit least(greatest(coalesce(p_quanti, 20), 1), 50);
$$;

revoke all on function public.feed_ospite(timestamptz, text, int) from public;
grant execute on function public.feed_ospite(timestamptz, text, int) to anon, authenticated;
```

```js
import { supabase } from './supabase'
import { voceStorico } from './storico'

// Il feed di chi non ha un account (pages/FeedOspite): `feed_ospite` in
// supabase/migrations/20261125120000_feed_ospite.sql.

export const PAGINA_OSPITE = 20

export function postOspiteDaRiga(r) {
  return {
    voce: voceStorico({ utenteId: r.user_id, utenteNome: r.nome || '', schedaId: r.scheda_id, completamento: r.dati }),
    foto: Array.isArray(r.foto) ? r.foto : [],
    interazioni: { miPiace: Number(r.mi_piace) || 0, mio: false, commenti: Number(r.commenti) || 0, ultimo: null },
  }
}

export async function leggiFeedOspite(dopo = null) {
  const { data, error } = await supabase.rpc('feed_ospite', {
    p_prima_di: dopo?.data ?? null,
    p_prima_di_id: dopo?.id ?? null,
    p_quanti: PAGINA_OSPITE,
  })
  if (error) {
    console.warn('Lettura del feed ospite fallita', error.message)
    return { ok: false, post: [], ancora: false, dopo }
  }
  const righe = data || []
  const ultima = righe.at(-1)
  return {
    ok: true,
    post: righe.map(postOspiteDaRiga),
    ancora: righe.length === PAGINA_OSPITE,
    dopo: ultima ? { data: ultima.data, id: ultima.id } : dopo,
  }
}
```

import { useEffect, useState } from 'react'
import PostSchermo from '../components/PostSchermo'
import { chiaveAllenamento } from '../lib/fotoAllenamento'
import { chiediAccount } from '../lib/ospite'
import { leggiFeedOspite } from '../lib/feedOspite'

// Il feed vero per l'ospite (lib/ospite): i post pubblici degli account
// pubblici, in sola lettura. Mi piace, commenti, condividere, aprire il
// recap → "Crea un account" (components/Ospite, FoglioAccount).

const chiedi = () => chiediAccount('feed')

export default function FeedOspite() {
  const [stato, setStato] = useState({ caricando: true, ok: true, post: [], ancora: false, dopo: null })

  const leggi = (dopo, prima = []) => {
    setStato((s) => ({ ...s, caricando: true }))
    leggiFeedOspite(dopo).then((r) => setStato({ caricando: false, ok: r.ok, post: [...prima, ...r.post], ancora: r.ancora, dopo: r.dopo }))
  }

  useEffect(() => {
    leggi(null)
  }, [])

  if (stato.post.length === 0) {
    return (
      <div className="feed-schermo">
        <div className="post-schermo post-vuoto">
          {stato.caricando ? <p>Un attimo…</p> : <p>{stato.ok ? 'Nessun allenamento pubblico, per ora.' : 'Non sono riuscito a caricare il feed.'}</p>}
        </div>
      </div>
    )
  }

  return (
    <div className="feed-schermo">
      {stato.post.map((p) => (
        <PostSchermo
          key={`${p.voce.utenteId}-${chiaveAllenamento(p.voce)}`}
          voce={p.voce}
          foto={p.foto}
          interazioni={p.interazioni}
          onApri={chiedi}
          onMiPiace={chiedi}
          onApriMiPiace={chiedi}
          onApriCommenti={chiedi}
          onCondividi={chiedi}
        />
      ))}
      <div className="feed-fondo">
        {stato.caricando ? (
          <p className="muted">Un attimo…</p>
        ) : stato.ancora ? (
          <button type="button" className="btn btn-ghost" onClick={() => leggi(stato.dopo, stato.post)}>
            Altri allenamenti
          </button>
        ) : null}
      </div>
    </div>
  )
}
