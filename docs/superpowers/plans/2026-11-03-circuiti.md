> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "+ EMOM" diventa "+ Circuito" con cinque tipi — A giri, EMOM, Tabata, AMRAP, For time — nell'editor, in allenamento, nell'import, nel recap/storico e nell'esportazione.

**Architecture:** si generalizza l'EMOM già fatto. `lib/emom.js` diventa `lib/circuiti.js` (una funzione per conto, un `switch` per tipo); il campo `emom` sul primo esercizio del blocco diventa `circuito: { tipo, … }`, convertito al caricamento. In allenamento resta la card di sempre con l'orologio in cima; AMRAP e For time aggiungono "Giro fatto" e un foglio di fine.

**Tech Stack:** React 19 + Vite, JS senza TypeScript, prove con `node --test` (`npm run test`), lint con `npm run lint`.

**Spec:** `docs/superpowers/specs/2026-11-03-circuiti-design.md` (e, per quello che c'è già, `docs/superpowers/specs/2026-11-03-emom-design.md`)

## Global Constraints

- **Nessuna modifica al database.** Tutto nel JSON di scheda e allenamento.
- Si lavora su **`main`**. **Non pushare** (l'utente tiene fermo il push dell'EMOM finché non c'è questo).
- Codice e commenti **in italiano**; niente punto e virgola, apici singoli, righe ≤ 120; ogni file segue il suo stile di estensione negli import.
- Tipi e testi: `emom` → "EMOM", `tabata` → "Tabata", `amrap` → "AMRAP", `fortime` → "For time", `giri` → "A giri" (nel menu) / "Circuito" (in testata).
- Valori di base: EMOM ogni 60" per 12'; Tabata lavoro 20", riposo 10", 8 giri; AMRAP 12'; For time 3 giri senza cap; A giri 3 giri, recupero 90".
- `PRONTI_SEC = 5` per tutti i tipi a orologio (EMOM, Tabata, AMRAP, For time). Niente pausa.
- **Ruling sulla spec §1 ("A giri non ha campo")**: A giri salva `circuito: { tipo: 'giri', giri, recuperoSec }`, se no un "A giri" appena creato con un esercizio solo non si distingue da un esercizio normale e non ha il riquadro. In allenamento si comporta come la superserie di oggi (nessun orologio). Le superserie vecchie, senza campo, restano come sono.
- **Ruling sulla spec §3 (Tabata)**: durante il riposo la card resta sull'esercizio APPENA fatto (è quello da valutare); passa al successivo all'inizio del lavoro dopo. È la stessa regola dell'EMOM.
- **Ruling sulla spec §1 ("la sessione ripresa")**: si converte solo la scheda (`normalizzaScheda`). Un allenamento EMOM già in corso al momento dell'aggiornamento perde l'orologio: succede solo in locale all'utente.
- Le serie "fatte senza sforzo" sono `colore: 'fatto'` (esiste già, pallino grigio).

// ---------------------------------------------------------------------------
// I CIRCUITI: esercizi di fila con un modo loro di contare. Come la
// SUPERSERIE (lib/superserie) — i successivi hanno `insiemeAlPrecedente` —
// con le impostazioni sul primo:
//
//   circuito: { tipo: 'giri',    giri: 3, recuperoSec: 90 }
//   circuito: { tipo: 'emom',    ogniSec: 60, minuti: 12 }          // minuti null = finché ce la faccio
//   circuito: { tipo: 'tabata',  lavoroSec: 20, riposoSec: 10, giri: 8 }
//   circuito: { tipo: 'amrap',   minuti: 12 }
//   circuito: { tipo: 'fortime', giri: 3, capMinuti: 20 }          // capMinuti null = senza limite
//
// Le serie di ognuno si CALCOLANO (allineaCircuiti) ma si scrivono nello
// schema: recap, volume, storico ed esportazione le leggono come serie normali.
// In allenamento (WorkoutSession, components/CardCircuito) l'orologio si
// calcola dall'istante di partenza `inizio` (ms); a fine circuito l'allenamento
// svolto tiene i risultati: `intervalliFatti` (EMOM, Tabata), `giriFatti` e
// `ripExtra` (AMRAP), `giriFatti` e `tempoSec` (For time).
// Spec: docs/superpowers/specs/2026-11-03-circuiti-design.md
// ---------------------------------------------------------------------------
import { faseVuota, formattaSecondi, normalizzaSchema } from './schema.js'
import { blocchi } from './superserie.js'

export const OGNI_PROPOSTI = [30, 45, 60, 90, 120, 180]
export const MINUTI_MAX = 60
// I secondi di "Pronti… 3, 2, 1" fra ▶ e il via.
export const PRONTI_SEC = 5

// L'ordine del menu "+ Circuito".
export const TIPI_CIRCUITO = [
  { id: 'giri', nome: 'A giri' },
  { id: 'emom', nome: 'EMOM' },
  { id: 'tabata', nome: 'Tabata' },
  { id: 'amrap', nome: 'AMRAP' },
  { id: 'fortime', nome: 'For time' },
]

/** Il nome in testata: "A giri" nel menu, "Circuito" sul riquadro. */
export function nomeCircuito(tipo) {
  return tipo === 'giri' ? 'Circuito' : TIPI_CIRCUITO.find((t) => t.id === tipo)?.nome || 'Circuito'
}

export const CIRCUITO_INIZIALE = {
  giri: { tipo: 'giri', giri: 3, recuperoSec: 90 },
  emom: { tipo: 'emom', ogniSec: 60, minuti: 12 },
  tabata: { tipo: 'tabata', lavoroSec: 20, riposoSec: 10, giri: 8 },
  amrap: { tipo: 'amrap', minuti: 12 },
  fortime: { tipo: 'fortime', giri: 3, capMinuti: null },
}

/** Ha un orologio suo (tutti tranne A giri, che usa il recupero di sempre). */
export function conOrologio(c) {
  return !!c && c.tipo !== 'giri'
}

/** Il campo di prima (`emom`, 144ª) col nome nuovo. Senza, lo stesso oggetto. */
export function circuitoDaEmom(e) {
  if (!e?.emom) return e
  const { emom, ...resto } = e
  const { minutiFatti, ...c } = emom
  return { ...resto, circuito: { tipo: 'emom', ...c, ...(minutiFatti != null ? { intervalliFatti: minutiFatti } : {}) } }
}

/** Quanti intervalli (EMOM: il pezzo di minuto che avanza non si fa; Tabata: i giri). null = a oltranza / non conta. */
export function intervalli(c) {
  if (c?.tipo === 'tabata') return c.giri
  if (c?.tipo !== 'emom' || c.minuti == null) return null
  return Math.max(1, Math.floor((c.minuti * 60) / c.ogniSec))
}

/** Le serie dell'esercizio k (da 0) su n. null = nascono in allenamento (AMRAP, EMOM a oltranza). */
export function serieCircuito(c, n, k) {
  if (c.tipo === 'giri' || c.tipo === 'fortime') return c.giri
  const tot = intervalli(c)
  return tot == null ? null : Math.max(0, Math.ceil((tot - k) / n))
}

/** All'intervallo m (da 0) tocca l'esercizio k del blocco, alla sua serie j. */
export function esercizioDelMinuto(n, m) {
  return { k: m % n, j: Math.floor(m / n) }
}

/**
 * Dov'è l'orologio. `fase`: 'pronti' (i primi PRONTI_SEC), 'lavoro' (EMOM,
 * Tabata), 'riposo' (Tabata), 'corre' (AMRAP, For time), 'fine'. `numero`: i
 * secondi da mostrare — alla rovescia, o in avanti nel For time. `intervallo`:
 * quello in corso (da 0) per EMOM e Tabata, null per gli altri.
 */
export function statoOrologio(c, inizio, adesso) {
  const t = (adesso - inizio) / 1000 - PRONTI_SEC
  if (t < 0) return { fase: 'pronti', numero: Math.ceil(-t), intervallo: 0, finito: false }
  if (c.tipo === 'emom') {
    const m = Math.floor(t / c.ogniSec)
    const tot = intervalli(c)
    if (tot != null && m >= tot) return { fase: 'fine', numero: 0, intervallo: tot, finito: true }
    return { fase: 'lavoro', numero: Math.ceil(c.ogniSec * (m + 1) - t), intervallo: m, finito: false }
  }
  if (c.tipo === 'tabata') {
    const ciclo = c.lavoroSec + c.riposoSec
    const m = Math.floor(t / ciclo)
    if (m >= c.giri) return { fase: 'fine', numero: 0, intervallo: c.giri, finito: true }
    const r = t - m * ciclo
    return r < c.lavoroSec
      ? { fase: 'lavoro', numero: Math.ceil(c.lavoroSec - r), intervallo: m, finito: false }
      : { fase: 'riposo', numero: Math.ceil(ciclo - r), intervallo: m, finito: false }
  }
  if (c.tipo === 'amrap') {
    const durata = c.minuti * 60
    if (t >= durata) return { fase: 'fine', numero: 0, intervallo: null, finito: true }
    return { fase: 'corre', numero: Math.ceil(durata - t), intervallo: null, finito: false }
  }
  // For time: in avanti; finisce col cap (i giri li chiude chi li segna).
  const cap = c.capMinuti != null ? c.capMinuti * 60 : null
  if (cap != null && t >= cap) return { fase: 'fine', numero: cap, intervallo: null, finito: true }
  return { fase: 'corre', numero: Math.floor(t), intervallo: null, finito: false }
}

/** Finito e coi suoi risultati (chi lo chiude: lib/session). */
export function circuitoChiuso(c) {
  return c.intervalliFatti != null || c.giriFatti != null
}

/** La testata: "EMOM 12' · ogni 1'", "AMRAP 12' · 7 giri + 5"… */
export function testoCircuito(c) {
  const s = formattaSecondi
  if (c.tipo === 'giri') return [`Circuito · ${c.giri} giri`, c.recuperoSec ? `rec ${s(c.recuperoSec)}` : null].filter(Boolean).join(' · ')
  if (c.tipo === 'emom') {
    const ogni = `ogni ${s(c.ogniSec)}`
    const tot = intervalli(c)
    const fatti = c.intervalliFatti
    if (fatti != null && (tot == null || fatti < tot)) {
      return `EMOM · ${ogni} · ${c.ogniSec === 60 ? `fino al ${fatti}° minuto` : `${fatti} intervalli`}`
    }
    return tot == null ? `EMOM · ${ogni} · finché ce la faccio` : `EMOM ${c.minuti}' · ${ogni}`
  }
  if (c.tipo === 'tabata') {
    const base = `Tabata ${s(c.lavoroSec)}/${s(c.riposoSec)} × ${c.giri}`
    return c.intervalliFatti != null && c.intervalliFatti < c.giri ? `${base} · fino al ${c.intervalliFatti}° giro` : base
  }
  if (c.tipo === 'amrap') {
    if (c.giriFatti == null) return `AMRAP ${c.minuti}'`
    return `AMRAP ${c.minuti}' · ${c.giriFatti} giri${c.ripExtra ? ` + ${c.ripExtra}` : ''}`
  }
  const cap = c.capMinuti != null ? `cap ${c.capMinuti}'` : null
  if (c.giriFatti == null) return [`For time · ${c.giri} giri`, cap].filter(Boolean).join(' · ')
  if (c.giriFatti >= c.giri) return `For time · ${c.giri} giri · ${s(c.tempoSec)}`
  return [`For time · ${c.giriFatti} giri su ${c.giri}`, cap].filter(Boolean).join(' · ')
}

/** Il turno dell'esercizio k su n: "1° di 2" (da solo null). */
export function turnoCircuito(n, k) {
  return n > 1 ? `${k + 1}° di ${n}` : null
}

/**
 * Gli esercizi di una SCHEDA con ogni circuito in ordine: `circuito` solo sul
 * primo (preso da chiunque del blocco ce l'abbia), le serie calcolate, una
 * fase sola, niente settimane diverse; il recupero c'è solo in A giri,
 * sull'ultimo (è quello di fine giro); nel Tabata le reps vuote sono "max".
 * Chi non è in un circuito resta lo stesso oggetto. Si lancia dopo ogni
 * modifica della lista e in normalizzaScheda.
 */
export function allineaCircuiti(esercizi) {
  const out = [...(esercizi || [])]
  for (const b of blocchi(out)) {
    const c = b.indici.map((i) => out[i].circuito).find(Boolean) || null
    const n = b.indici.length
    b.indici.forEach((i, k) => {
      let e = out[i]
      if (k > 0 && e.circuito) {
        const { circuito: _, ...resto } = e
        e = resto
      }
      if (c) {
        if (k === 0 && e.circuito !== c) e = { ...e, circuito: c }
        const serie = serieCircuito(c, n, k)
        const recuperoSec = c.tipo === 'giri' && k === n - 1 ? (c.recuperoSec ?? null) : null
        const s = normalizzaSchema(e.schemaBase)
        const f = s.fasi[0] || faseVuota()
        const rip = c.tipo === 'tabata' && f.rip == null ? 'max' : f.rip
        if (s.fasi.length !== 1 || f.serie !== serie || f.rip !== rip || s.recuperoSec !== recuperoSec || e.variaPerSettimana) {
          e = { ...e, variaPerSettimana: false, schemaBase: { ...s, fasi: [{ ...f, serie, rip }], recuperoSec } }
        }
      }
      out[i] = e
    })
  }
  return out
}

/** Il circuito dell'esercizio i: le impostazioni, quanti sono (n), lui chi è (k), il blocco. */
export function posizioneCircuito(esercizi, i) {
  const blocco = blocchi(esercizi).find((b) => b.indici.includes(i))
  const circuito = blocco && esercizi[blocco.inizio]?.circuito
  return circuito ? { circuito, n: blocco.indici.length, k: blocco.indici.indexOf(i), blocco } : null
}

/** "Sciogli": il blocco dell'esercizio `id` torna esercizi normali, slegati. */
export function sciogliCircuito(esercizi, id) {
  const i = esercizi.findIndex((e) => e.id === id)
  const blocco = blocchi(esercizi).find((b) => b.indici.includes(i))
  if (!blocco) return esercizi
  return esercizi.map((e, k) => {
    if (!blocco.indici.includes(k)) return e
    const { circuito: _, ...resto } = e
    return { ...resto, insiemeAlPrecedente: false }
  })
}

 * Cosa mostra la card del blocco in allenamento: `scelto` (un pallino o un
 * esercizio toccato), se no — EMOM e Tabata, orologio in corso — chi tocca
 * nell'intervallo (nel riposo del Tabata chi l'ha appena fatto, da valutare);
 * altrimenti il primo esercizio alla sua prima serie non data.
 */
export function vistaCircuito(esercizi, blocco, scelto, adesso = Date.now()) {
  if (scelto) return scelto
  const c = esercizi[blocco.inizio].circuito
  if ((c.tipo === 'emom' || c.tipo === 'tabata') && c.inizio != null && !circuitoChiuso(c)) {
    const s = statoOrologio(c, c.inizio, adesso)
    if (s.fase === 'lavoro' || s.fase === 'riposo') {
      const { k, j } = esercizioDelMinuto(blocco.indici.length, s.intervallo)
      return { i: blocco.indici[k], j }
    }
  }
  const i = blocco.indici[0]
  const j = esercizi[i].sets.findIndex((x) => !x.colore)
  return { i, j: j === -1 ? 0 : j }
}

```js
/**
 * EMOM e Tabata: a ogni intervallo nuovo l'esercizio di turno ha la sua serie
 * (da dare), se manca — a oltranza, o oltre le 30 della sessione. Fino
 * all'intervallo `intervallo` (da 0) compreso. Niente da aggiungere: la stessa lista.
 */
export function serieCircuitoFinoA(esercizi, blocco, intervallo) {
  const n = blocco.indici.length
  let cambiato = false
  const out = esercizi.map((e, i) => {
    const k = blocco.indici.indexOf(i)
    if (k === -1) return e
    const servono = intervallo >= k ? Math.floor((intervallo - k) / n) + 1 : 0
    if (e.sets.length >= servono) return e
    cambiato = true
    return { ...e, sets: [...e.sets, ...Array.from({ length: servono - e.sets.length }, () => ({ colore: null }))] }
  })
  return cambiato ? out : esercizi
}

/**
 * Fine di un EMOM o di un Tabata (finito, "Ferma", "Non ce la faccio più",
 * "Termina"): valgono i primi `fatti` intervalli. Le serie oltre si tolgono;
 * quelle non date valgono fatte come da piano, senza sforzo (`'fatto'`).
 */
export function chiudiCircuito(esercizi, blocco, fatti) {
  const n = blocco.indici.length
  const tutte = fatti > 0 ? serieCircuitoFinoA(esercizi, blocco, fatti - 1) : esercizi
  return tutte.map((e, i) => {
    const k = blocco.indici.indexOf(i)
    if (k === -1) return e
    const quante = fatti > k ? Math.ceil((fatti - k) / n) : 0
    return {
      ...e,
      ...(k === 0 ? { circuito: { ...e.circuito, intervalliFatti: fatti } } : {}),
      sets: e.sets.slice(0, quante).map((s, j) => (s.colore ? s : serieChiusa(e.schema, j, 'fatto'))),
    }
  })
}

/** AMRAP e For time: i giri fatti sono le serie date del primo esercizio. */
export function giriFattiDi(esercizi, blocco) {
  return esercizi[blocco.inizio].sets.filter((s) => s.colore).length
}

/** "Giro fatto": a ogni esercizio del blocco la sua serie in più, fatta come da piano. */
export function giroFatto(esercizi, blocco) {
  const j = giriFattiDi(esercizi, blocco)
  return esercizi.map((e, i) => {
    if (!blocco.indici.includes(i)) return e
    const sets = [...e.sets]
    while (sets.length <= j) sets.push({ colore: null })
    sets[j] = serieChiusa(e.schema, j, 'fatto')
    return { ...e, sets }
  })
}

/**
 * Fine di un AMRAP o di un For time: restano le serie dei giri fatti (quella
 * del giro non finito si toglie), e sul circuito i risultati.
 */
export function chiudiAGiri(esercizi, blocco, { giriFatti, tempoSec = null }) {
  return esercizi.map((e, i) => {
    const k = blocco.indici.indexOf(i)
    if (k === -1) return e
    return {
      ...e,
      ...(k === 0
        ? { circuito: { ...e.circuito, giriFatti, ...(tempoSec != null ? { tempoSec } : {}) } }
        : {}),
      sets: e.sets.slice(0, giriFatti).map((s, j) => (s.colore ? s : serieChiusa(e.schema, j, 'fatto'))),
    }
  })
}

/**
 * "Com'è andata?" una volta sola, a AMRAP o For time finito: il colore su
 * tutte le serie del blocco; `ripExtra` (AMRAP) sul circuito. colore null =
 * saltato: le serie restano 'fatto'.
 */
export function esitoCircuito(esercizi, blocco, { colore = null, ripExtra = null }) {
  return esercizi.map((e, i) => {
    const k = blocco.indici.indexOf(i)
    if (k === -1) return e
    return {
      ...e,
      ...(k === 0 && ripExtra ? { circuito: { ...e.circuito, ripExtra } } : {}),
      sets: colore ? e.sets.map((s) => ({ ...s, colore })) : e.sets,
    }
  })
}

/**
 * "Termina" con un circuito ancora in corso: lo si chiude dov'è. EMOM e
 * Tabata: valgono gli intervalli finiti (nel riposo del Tabata quello appena
 * fatto sì). AMRAP e For time: i giri segnati, e il For time il tempo.
 */
export function chiudiCircuitiAperti(esercizi, adesso) {
  let out = esercizi
  for (const b of blocchi(esercizi)) {
    const c = esercizi[b.inizio].circuito
    if (!c || c.tipo === 'giri' || c.inizio == null || circuitoChiuso(c)) continue
    const s = statoOrologio(c, c.inizio, adesso)
    if (c.tipo === 'emom' || c.tipo === 'tabata') {
      const fatti = s.finito ? intervalli(c) : s.fase === 'pronti' ? 0 : s.intervallo + (s.fase === 'riposo' ? 1 : 0)
      out = chiudiCircuito(out, b, fatti ?? s.intervallo)
    } else {
      const tempoSec = Math.max(0, Math.floor((adesso - c.inizio) / 1000) - PRONTI_SEC)
      out = chiudiAGiri(out, b, { giriFatti: giriFattiDi(out, b), ...(c.tipo === 'fortime' ? { tempoSec } : {}) })
    }
  }
  return out
}

export function MotoreCircuito({ circuito: c, onMinuto, onCresci, onChiudi }) {
  const { stato } = useOrologio(c)
  const ultimo = useRef(null)
  const chiave = stato && stato.fase !== 'pronti' ? `${stato.fase}:${stato.intervallo}` : null

    if (chiave == null) return
    if (stato.finito) {
      onChiudi(stato)
      return
    }
    if (ultimo.current === chiave) return

      navigator.vibrate?.(200)

    ultimo.current = chiave
    if (stato.fase === 'lavoro') onCresci(stato.intervallo)
    onMinuto()
  }, [chiave, stato?.finito]) // eslint-disable-line react-hooks/exhaustive-deps

// rounds:", "EMOM 12':", "E2MOM 16':", "Tabata:", "Tabata 30/15 x6:", "AMRAP

function circuitoDa(t) {
  const due = t.indexOf(':')
  const testa = (due === -1 ? t : t.slice(0, due)).trim()
  const dopo = due === -1 ? '' : t.slice(due + 1).trim()
  if (due === -1 && !/^tabata$/i.test(testa)) return null
  let m
  if ((m = testa.match(/^e(\d)?mom\b(.*)$/i))) {
    let ogniSec = (m[1] ? parseInt(m[1], 10) : 1) * 60
    const ogni = m[2].match(/ogni\s+(\S+)/i)
    if (ogni) ogniSec = parseRecuperoSec(ogni[1]) || ogniSec
    ogniSec = Math.max(15, ogniSec)
    const oltranza = /finch[eé]|cediment|oltranza|\bmax\b/i.test(m[2])
    const min = m[2].replace(/ogni\s+\S+/i, '').match(/(\d+)\s*(?:'|’|min)/i)
    if (!oltranza && !min) return null
    return { circuito: { tipo: 'emom', ogniSec, minuti: oltranza ? null : parseInt(min[1], 10) }, dopo }
  }
  if ((m = testa.match(/^tabata\b(?:\s+(\d+)\s*\/\s*(\d+)(?:\s*[x×]\s*(\d+))?)?\s*$/i))) {
    const [, l, r, g] = m
    return {
      circuito: { tipo: 'tabata', lavoroSec: l ? +l : 20, riposoSec: r ? +r : 10, giri: g ? +g : 8 },
      dopo,
    }
  }
  if ((m = testa.match(/^amrap\s+(\d+)\s*(?:'|’|min)/i))) return { circuito: { tipo: 'amrap', minuti: +m[1] }, dopo }
  if (/for\s*time/i.test(testa)) {
    const giri = testa.match(/(\d+)\s*(?:giri|rounds?)/i)
    const cap = testa.match(/cap\s*(\d+)/i)
    return { circuito: { tipo: 'fortime', giri: giri ? +giri[1] : 1, capMinuti: cap ? +cap[1] : null }, dopo }
  }
  if ((m = testa.match(/^(?:circuito\s+)?(\d+)\s*(?:giri|rounds?)\b(.*)$/i))) {
    const rec = m[2].match(/rec(?:upero)?\.?\s*(\S+)/i)
    return { circuito: { tipo: 'giri', giri: +m[1], recuperoSec: rec ? parseRecuperoSec(rec[1]) || null : null }, dopo }
  }
  return null
}
```

Nel ciclo, dove oggi c'è `const em = emomDa(t)`: `const ci = circuitoDa(t)` con `circuitoAperto = ci.circuito`. La regola "numero in fondo = reps" vale per tutti i tipi (`nellCircuito`). Il controllo "serie scritte che non tornano" usa `serieCircuito` (per AMRAP è null: niente controllo).
